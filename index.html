NK Model Explorer

An organization makes N yes/no decisions. Each decision's payoff depends on its own setting and on K other decisions. When K = 0 the decisions don't interact, so the landscape is smooth with a single peak. As K rises, the decisions become tangled together. The landscape turns rugged, local peaks multiply, and step-by-step improvement gets stuck. Use the controls to see this happen.

How to read this map

The three axes. The decisions are split into two groups, one for each floor axis. One axis runs through every combination of the first group of decisions, and the other runs through the second group. The vertical axis is fitness. So every bar (or point on the surface) is one complete configuration, and its height shows how well that configuration performs.

Who's next to whom. Each floor axis is ordered using a Gray code, so any two configurations that sit side by side differ by exactly one decision. But each configuration has N one-step neighbors, and at most four of them can sit beside it on the floor. The rest are elsewhere. That's why hovering highlights neighbors that are spread around, and why a searcher's single step can jump across the landscape. The smooth surface is a curve drawn through every configuration's real fitness. The slopes between configurations are there so you can see the shape; only the configurations themselves are real choices. Switch to bars for the literal picture, with each configuration as a separate column.

4. Experiment: what happens as K rises?

Try this

  1. Smooth world. Set K = 0 and press Play. There's exactly one peak, and every searcher reaches it. When choices don't interact, you can improve them one at a time.
  2. Add interdependence. Raise K a step at a time and scatter new searchers each time. Watch the number of local peaks climb and the neighbor correlation fall. More and more searchers end up stuck (gray squares).
  3. Maximum ruggedness. Set K = N−1. Every decision affects every other one, so the landscape is close to random. Where a searcher ends up depends heavily on where it started.
  4. Exploration vs. exploitation. Keep K high and turn up the long-jump chance. Do searchers escape their local peaks? How much does the extra exploration cost along the way?
  5. Run the K sweep. Explain the shape of both curves. Why does the average searcher do worse as K rises, even though the best configuration is still out there?

Strategy link. N is the number of choices that make up a strategy or organizational design. K is how tightly they fit together. Steepest ascent is incremental improvement, and a long jump is a radical reorganization. High-K strategies are hard to find, but they're also hard for rivals to imitate one piece at a time (see Levinthal, 1997; Rivkin, 2000).
